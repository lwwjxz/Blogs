pyenv是管理python版本的。     
python不支持安装同一个包的不同版本，需要用不同版本可以用venv创建虚拟环境     
venv用来创建虚拟环境     
```
python -m venv 环境名     

# 激活虚拟环境    
source 虚拟环境目录/bin/activate    

# 完成后，退出虚拟环境   
deactivate   

# 验证是否已退出  
which python  # 应该显示系统 Python 路径，而不是虚拟环境中的路径  
  

```

python版本是多少虚拟环境中的python版本号就是多少      
虚拟环境的激活状态与当前工作目录无关。它是基于会话的，会话指的是终端链链    

uv 和 venv作用一样。基于会话的。

# 选择建议：

简单项目：venv
大型项目：uv
追求性能：uv

```

# 安装uv
pip install uv

# 创建虚拟环境
uv venv

# 激活虚拟环境
$ source .venv/bin/activate
(.venv) $ 

# 此时 Python 环境已切换到虚拟环境

# 安装包
(.venv) $ pip install numpy

# 运行 Python 解释器
(.venv) $ python
>>> import numpy
# 能正确导入 numpy 包

# 退出虚拟环境
(.venv) $ deactivate
$
# 此时已经回到系统全局的 Python 环境

# 进入项目目录 使用 uv sync 命令来保证 python 版本和相关依赖包的一致性
uv sync

```

by 目录指定python版本
```
pyenv local 3.9.16 命令的作用是：

为当前目录设置特定的 Python 版本
详细解释：

在当前目录创建一个 .python-version 文件
只在这个目录及其子目录使用 3.9.16 版本的 Python
进入这个目录时自动切换到 3.9.16 版本
离开目录时自动恢复之前的 Python 版本

```
